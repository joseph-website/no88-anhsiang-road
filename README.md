## 📁 案件背景：雨夜的叩門聲 (Case Dossier: Prologue)

```text
【機密委託備忘錄 // 案號：2012-AH-088】
委託日期：2012 年 10 月 17 日 • 陰雨
委託人：陳先生（自由業者）
協尋對象：張浩（32歲，自由建築設計師）
最後已知地點：安祥路88號集合住宅大樓 504 室
```

2012 年深秋，連綿冰冷的夜雨籠罩著這座城市。  
私家偵探事務所的百葉窗外霓虹閃爍，委託人**陳先生**面色蒼白地推開了事務所大門。他的摯友、建築設計師**張浩**，在一週前搬入「安祥路88號」後音訊全無。

起初只是一通簡短的報平安電話；然而三天後的深夜兩點，陳先生接到了張浩打來的最後一通通話——電話另一端充斥著沉重的喘息、金屬門把被反覆狂亂轉動的摩擦聲，以及斷線前戛然而止的呼救。

你收下泛黃的租賃合約與筆記本，驅車前往這座座落在老城區邊緣的舊公寓大樓。  
然而，當你踏入大廳的瞬間，空氣中壓抑的沉寂便敲響了警鐘：
- 昏暗的值班台後，老警衛眼神閃避、言詞推託，深鎖的抽屜裡似乎藏著不可告人的登記冊；
- 冰冷的水泥走廊深處，隱約迴盪著時斷時續的微弱敲擊聲；
- 梯廳的電表指針無聲轉動，各層住戶房門緊閉，空氣中瀰漫著舊紙張與石膏粉塵的氣味；
- 這座看似尋常的集合住宅，彷彿正以某種無聲的姿態，吞噬著所有踏入其中的痕跡……

作為受託調查員，你必須深入這座充滿疑雲的大樓，在有限的理智與心理壓力下搜集現場物證、辨識可疑細節，揭開張浩失聯背後深藏的真相。

## 🔍 核心調查機制 (Investigative Systems)

### 1. 六大偵探思維特質 (Six Cognitive Archetypes)
在事務所整理案情準備出發時，你的直覺選擇將喚醒專屬的辦案風格。遊戲內建 6 種截然不同的思維特質，賦予獨特的調查洞察與心理適應機制：

* **🧠 理性 (Rationalist) — 邏輯懷疑論者**  
  > *「萬物皆有因果，沒有任何離奇表象能凌駕於客觀鐵證之上。」*  
  以嚴密的因果邏輯剖析現場，在推演案情與整理核心物證時能快速撫平焦慮，維持冷靜心智。

* **👁️ 直覺 (Intuitive) — 直覺靈感派**  
  > *「當後頸泛起寒意時，直覺往往比雙眼更快嗅出危險。」*  
  擁有超乎常人的「第六感」天賦，在未知危機逼近或即將觸碰關鍵線索前，能提前感應並觸發直覺預警。

* **🛡️ 慎重 (Cautious) — 生還防禦者**  
  > *「活著走出這棟樓，才是唯一能將真相公諸於世的偵探。」*  
  危機嗅覺極高，行動嚴謹。在明亮處或安全據點（如值班台）能顯著平復心律，具備極強的生還防線。

* **🔬 細心 (Deconstructor) — 細微洞察者**  
  > *「最不起眼的文字遺漏與空間痕跡，往往就是推倒迷局的第一塊骨牌。」*  
  明察秋毫，善於在堆疊的雜亂檔案中抽絲剝繭捕捉人為漏洞，現場物證分析回饋極高。

* **🎭 敏銳 (Empath) — 洞察側寫師**  
  > *「空間會呼吸，人會說謊；但恐懼留下的痕跡絕不會褪色。」*  
  擅長捕捉環境氛圍的細微異樣與人物心理動機，面對極端情境壓迫時擁有卓越的心理調適彈性。

* **⚡ 勇敢 (Pragmatist) — 現場實踐派**  
  > *「與其在門外反覆猜測，不如握緊手電筒，直接推開那扇門。」*  
  行事雷厲風行，在突發危機與現場對峙中具備強韌的心理素質，主動勘查新區域時鬥志高昂。

### 2. 現場動態搜查與黑暗穿透 (Dynamic Crime Scene Forensics)
- **多樓層立體搜查**：自由穿梭一樓大廳、警衛安控室、各樓層梯廳走廊、折返式雙跑安全梯與住戶室內。
- **動態環境熱點**：排查數十處現場物件——撕碎的信件殘片、反常的電表回路、停擺的梯廳掛鐘、深鎖的防護門扉。
- **戰術手電筒（Tactical Flashlight）**：暗處的光束能照映出肉眼難辨的細微刮痕、血字暗號與特殊標記。

---

### 3. 軟木塞案情推導盤 (Corkboard Deduction Matrix)
- **視覺化線索連結**：將現場採集到的口供證言、手寫紙條與實體物件釘上軟木塞板，自由拉出紅線串聯因果假設。
- **偵探手帳與隨身物證袋**：隨時翻閱已建檔的案件照片、現場錄音備忘與偵探即時日誌。

---

### 4. 現場現場微解謎與應變挑戰 (Forensic Minigames & Encounters)
- **碎紙信件復原 (Letter Puzzle)**：旋轉與拼接散落各處的撕裂信件，拼湊出張浩失蹤前留下的關鍵手跡。
- **監視時空交叉矩陣 (CCTV Matrix)**：核對多路錄影畫面與時間戳記，在混亂的時間線中推敲目標的真實動線。
- **空間結構幾何丈量 (Staircase Measure)**：抽出鋼捲尺量測階梯高差，以精確的客觀數據審視大樓的空間異常。
- **走廊匿蹤反應 (Guard Patrol QTE)**：警衛沉重的腳步聲逼近時，在屏息中限時尋求隱蔽，避開視線。
- **緊急搜救行動 (Rescue Mission)**：融合聽音辨位、強光探照與物理破拆，爭分奪秒探尋失聯者的下落。

---

### 5. 即時程序化聲景系統 (Live Procedural Soundscape)
- **100% Web Audio 原生合成**：不依賴任何外部音訊檔案，全由瀏覽器即時運算合成。
- **擬真沉浸音場**：窗外低沉的秋雨聲、日光燈管斷續的電流嗡鳴、耳邊急促的心跳聲、老式錄音機的捲帶噪訊……每一個聲音都是感知周遭環境的感官延伸。
- **多軌混音控制**：支援環境氛圍、音效細節與背景旋律獨立音量精細調控。

---

### 6. 多分歧案件審查與 A4 官方結案書 (Branching Case Resolution)
- 你的搜查完整度、關鍵證物獲取率與現場抉擇，將引導案件走向完全不同的命運終局。
- 結案後系統自動為你封裝一份具備防偽印記與官方審查編號的 **A4 比例案件終局報告書**，支援一鍵轉存高解析度 PNG 檔案。

## ⌨️ 調查員操作指引 (Investigator Controls)

支援全鍵盤快速鍵與滑鼠雙操作模式（遊戲中可隨時按 `?` 檢視指引）：

| 按鍵 | 操作項目 | 功能說明 |
| :---: | :--- | :--- |
| <kbd>Tab</kbd> / <kbd>I</kbd> | **物證檔案袋** (Dossier) | 翻閱已搜集到的所有物件、照片與檔案清單 |
| <kbd>R</kbd> | **大樓規約手冊** (Rulebook) | 查閱大樓公告、工作指引與管委會條例文書 |
| <kbd>D</kbd> | **軟木塞推理盤** (Deduction Board) | 開啟案情推導盤，自由串聯線索建立因果假設 |
| <kbd>J</kbd> | **調查行動手帳** (Journal) | 檢視當前案件進度、重要證言與現場日誌 |
| <kbd>N</kbd> | **偵探隨手筆記** (Notes) | 自由記錄偵探備忘錄與推論想法 |
| <kbd>M</kbd> | **大樓方位指南針** (Compass) | 確認當前所在樓層與現場方位動線 |
| <kbd>G</kbd> | **全結局成就畫廊** (Gallery) | 檢視已解鎖的結案報告與調查歷程 |
| <kbd>F</kbd> | **戰術手電筒開關** (Flashlight) | 切換手電筒光源，探查暗處隱藏線索 |
| <kbd>O</kbd> | **凝神感知周遭** (Sense) | 靜下心神，捕捉當前空間的異樣反饋 |
| <kbd>S</kbd> | **多欄位存檔面板** (Save / Load) | 管理調查進度存檔與讀取記錄 |
| <kbd>Esc</kbd> | **快速關閉彈窗** (Close) | 立即關閉當前開啟的次級浮層與面板 |

## 🛠️ 開發與建構指南 (Getting Started)

### 運行環境
- Node.js 18.0 或以上版本
- npm / pnpm / yarn

### 指令清單

```bash
# 1. 安裝專案相依套件
npm install

# 2. 啟動本機開發伺服器 (預設連接埠: http://localhost:3000)
npm run dev

# 3. 執行 TypeScript 型別與語法檢查
npm run lint

# 4. 建構生產環境封裝檔案 (輸出至 dist/)
npm run build
```
